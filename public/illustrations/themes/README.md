# Wishlist theme artwork

Six locally hosted WebP designs, 1000 × 700 pixels, quality 82. The UI crops these
into thumbnails and shallow header strips; downloaded PNGs use a side strip.
Titles and QR codes stay on plain paper. No insect imagery is included.

## Occasion patterns

| File                      | Theme       | Motifs                                 |
| ------------------------- | ----------- | -------------------------------------- |
| `occasion-christmas.webp` | Christmas   | Evergreen branches, ornaments, ribbons |
| `occasion-birthday.webp`  | Birthday    | Cakes, candles, streamers              |
| `occasion-baby.webp`      | Baby & kids | Teddy bears, rocking horses, moons     |
| `occasion-love.webp`      | Love        | Hearts, ribbons, doves, flowers        |

Created for Wishlist on 25 October 2026 with the built-in image-generation tool,
then resized and encoded locally. This is newly generated artwork, **not**
archive imagery. No external services are called when the app displays or exports it.

### Generation prompts

Christmas prompt:

> Use case: illustration-story. Create a polished flat 3:2 landscape decorative textile/wrapping-paper design for the CHRISTMAS theme of Wishlist, a warm cream editorial gift-wishlist web app with dark charcoal serif headings. Artwork only, no UI and absolutely no text or letters. A sophisticated repeating all-over arrangement of individually hand-painted evergreen sprigs, red and muted ochre glass baubles, tiny gold stars, and cream ribbon bows on warm ivory paper. Printed gouache and vintage woodblock texture, subtle ink grain, organically imperfect edges, refined restrained flat colors: forest green, soft sage, faded vermilion, ochre, ivory. Motifs medium sized and easily recognizable when image is cropped into a shallow horizontal banner; fill the entire composition evenly with 2-3 rows, no central isolated icon and no large empty background. Beautiful premium stationery, not an emoji, not flat corporate SVG clip art, not a cute cartoon, no thick black outlines, no gradients or 3D, no photographic objects, no insects. This is the first of a coordinated set of four occasion patterns; prioritize elegant tactile printed detail and consistent scale.

## Historical patterns

Botanical and Waves use **Shin-Bijutsukai (1902)** via
[The Public Domain Image Archive](https://pdimagearchive.org) and
[The Public Domain Review](https://publicdomainreview.org/collection/japanese-designs-1902/).
The original scan is held by
[Smithsonian Libraries and Archives](https://archive.org/details/Shinbijutsukai1).

| File                        | Theme     | PDIA record                                                                              |
| --------------------------- | --------- | ---------------------------------------------------------------------------------------- |
| `shin-bijutsukai-0031.webp` | Botanical | [White flowers](https://pdimagearchive.org/images/1d411dd7-4d06-407f-817e-696735b0b794/) |
| `shin-bijutsukai-0016.webp` | Waves     | [Wave pattern](https://pdimagearchive.org/images/33abba18-67d6-4977-bff9-0c86da9bab0c/)  |

Source catalog: “Not in copyright”. PDIA rights labels: **Public Domain U.S.** for
the underlying works and **No Additional Rights** for the digital copies.
[PDIA reuse guidance](https://pdimagearchive.org/reusing-images/).

Original JPEG URL pattern:
`https://images.pdimagearchive.org/collections/shin-bijutsukai/shin-bijutsukai-NNNN.jpeg`,
where `NNNN` matches the filename above. Downloaded 24 October 2026 at width 1000,
then cropped to landscape and converted to WebP without recoloring.
