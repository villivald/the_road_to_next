# OpenMoji illustrations

Unmodified color SVGs from [OpenMoji 17.0.0](https://github.com/hfg-gmuend/openmoji/tree/17.0.0/color/svg), by the OpenMoji contributors at HfG Schwäbisch Gmünd.

- `gift.svg`: `1F381` (wrapped gift).
- `coffee.svg`: `2615` (hot beverage).
- `book.svg`: `1F4D6` (open book).
- `heart.svg`: `1F49D` (heart with ribbon).
