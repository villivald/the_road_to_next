# Wishlist

[Wishlist](https://wishlist.fi) helps people create and share wishlists, discover gift ideas, and coordinate gifts without duplicate reservations. Available in English and Finnish, with light and dark themes and a responsive mobile interface.

Free accounts include wishlists, wishes, favorites, and individual or group reservations. Premium adds private sharing and collaboration controls, guest links, list themes, QR sharing cards, and an optional profile badge.
